# Pipeline-Tennessee-Bureau-of-Regents

This repository outlines the data pipeline for permitting data from the Tennessee Bureau of Regents.  

All data is stored in a SQLite database called TBR that is located in the "Outputs" folder. A guide to this database called "DB_TBR_Metadata.xlsx" is located in the "Outputs" folder and should be updated whenever a new data series is added or updated.
